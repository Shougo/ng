# ng — Neovim のためのウィンドウ

ng は Go で書いた Linux 専用の Neovim GUI です。
GVim が Vim に対してそうであるように、ただのウィンドウを目指します。

## 約束

1. 文字は正しく描く。全角も曖昧幅もセルからはみ出さない。
2. 画面は Neovim の画面。端末で動くものは ng でも同じに見える。
3. 作業は ng より長生きする。ng が落ちても編集内容は残る。
4. 端末より速い。

## 文字幅

| 種類     | 例                             |
|----------|--------------------------------|
| 全角     | 日本語、漢字、カタカナ         |
| 半角カナ | ｱｲｳｴｵ ｶﾞｷﾞｸﾞ                   |
| 曖昧幅   | ○ △ □ ※ → ① ② ③ αβγ            |
| 記号     | 「括弧」『二重括弧』【隅付き】 |

変換中の文字列は、カーソルの位置にグリッドの中で描かれます。日本語入力
